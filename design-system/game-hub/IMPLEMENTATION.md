# Implementation direction

The generated MASTER.md is advisory. This application uses charcoal, warm off-white and lime instead of rose/blue, with DM Sans and Manrope for readable cross-age UI. Rounded tactile controls retain the playful direction without making the adult experience feel like a children's app.

The first screen is a playable game hub, so install buttons, app-store ratings, testimonials, and download sections from the generated landing-page pattern are omitted. No fabricated player counts or online activity. Future games are explicitly marked as unavailable.

Use 44px minimum touch targets, visible keyboard focus, clear form labels, reduced-motion support and responsive single-column rooms on phones.
